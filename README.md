# 🌐 Yemen Telecom Bypass (المنظومة الموحدة)

[![Android Build](https://github.com/jhad1234/Gradle/actions/workflows/android_build.yml/badge.svg)](https://github.com/jhad1234/Gradle/actions/workflows/android_build.yml)
[![License](https://img.shields.io/badge/License-MIT-green)](LICENSE)

المنظومة الموحدة والذكية لاستكشاف تقنيات تجاوز قيود الشبكة وخدمات الوصول لأنظمة الاتصالات في اليمن.

## 🚀 نظرة عامة (Overview)
هذا المشروع هو تطبيق أندرويد يهدف إلى استكشاف تقنيات تجاوز بعض قيود الشبكة باستخدام خدمات الوصول (Accessibility Services) وواجهات برمجة تطبيقات VPN الخاصة بالأندرويد لتحسين تجربة الاتصال.

## 🏗️ ميزات المنظومة (Key Features)
- **AccessibilityBypass**: تطبيق خدمة الوصول لأتمتة بعض التفاعلات.
- **LocalVpnService**: نموذج لإنشاء خدمة VPN محلية لتوجيه حركة المرور.
- **MainActivity**: واجهة المستخدم الرئيسية للتحكم في خدمات التجاوز.

## 🛠️ تعليمات البناء (Build Instructions)
يستخدم هذا المشروع **Gradle** لأتمتة البناء:
1. قم باستنساخ المستودع.
2. افتح المشروع في Android Studio.
3. قم ببناء الـ APK باستخدام الأمر: \`./gradlew assembleDebug\`.
